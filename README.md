# Spotify-Dashboard-PowerBi

## Overview
Interactive Spotify Analytics Dashboard built with Power BI, featuring data cleaning, DAX measures, KPI tracking, artist insights, song performance analysis, and dynamic visualizations.

## Features
- KPI Cards
- Artist Analysis
- Song Analysis
- Interactive Filters & Slicers
- DAX Measures
- Modern Dashboard Design

## Tools Used
- Power BI
- Microsoft Excel
- DAX
- Power Query

## Files
- Spotify Dashboard.pbix
- spotify_cleaned.xlsx
- Spotify_Dashboard.png

## Purpose
This project demonstrates data cleaning, data modeling, DAX calculations, and interactive dashboard design using Power BI to transform Spotify data into meaningful business insights.
